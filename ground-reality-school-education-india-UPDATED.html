Single-teacher schools

States with the most single-teacher schools

A single-teacher school has one teacher covering every grade taught there — a direct staffing-strain indicator available in this dataset
Flagged data anomaly: West Bengal's AY2024 row reports 23,549,432 students "enrolled in single-teacher schools" against a state total enrolment of ~17.08 million — a figure that is mathematically impossible and almost certainly a decimal/digit entry error in the source file. It is displayed as reported (not silently corrected or dropped) and excluded only from the single-teacher ranking chart above, which is population-weighted; the raw value remains visible in the State Ranking table.
Pupil–Teacher Ratio (PTR) = Total Students ÷ Total Teachers. A lower PTR means each teacher is, on average, responsible for fewer students. It does not by itself mean better teaching, better infrastructure or better learning outcomes — those require classroom-level and learning-assessment data this dashboard does not have. Treat PTR here as one input into teacher-availability planning, not a quality score.

Definitions used in this dashboard

GovernmentSchools UDISE+ classifies under state/central government management. Reported as a single "Government" figure in the national file; the state-wise file does not split by management, so no state-wise government count exists in this data.
Government AidedPrivately managed but government-aided schools, kept as its own category throughout — never merged into "Government" or "Private."
Private"Private Unaided Recognised" schools only, as labelled in the source. Unrecognised private schools are not part of UDISE+'s recognised-school universe and are not represented anywhere in this dashboard.
Academic yearTwo years only: AY2023 (2023–24) and AY2024 (2024–25), as labelled in the source files.
Pupil–Teacher Ratio (PTR)Reported directly by the state-wise file as a single state-level figure. Not recalculated, and not available split by education level, management type or rural/urban in this data.
Students per schoolReported by the source as avg_enrolment_per_school (state total enrolment ÷ state total schools).
Zero-enrolment schoolsRecognised schools with zero students on roll in a given year, as reported by the source; excluded from PTR since the ratio is undefined at zero.
Single-teacher schoolsSchools with exactly one teacher on staff, as reported by the source.
Missing dataDisplayed as "Data unavailable" or omitted from a chart — never estimated, interpolated or backfilled.
Survey vs. administrative dataBoth source files are administrative UDISE+ counts, not sample surveys. No ASER, NAS or NSS survey data is loaded, so no learning-outcome or expenditure survey figures appear anywhere in this dashboard.

Design simplifications, stated plainly

  • No geographic map: the source files contain no state-boundary (GeoJSON) data, so the brief's clickable India map is implemented as a clickable, sortable state table with the same filtering behaviour.
  • Only two academic years exist in the source, so trend lines show a two-point AY2023→AY2024 comparison rather than a multi-year series. The data structures below are written so additional years can be appended without redesign.
  • "Compare Government vs Private" filtering is available at the national level only (the management file), because the state-wise file has no management breakdown to filter by.

Extending this dashboard

To light up the greyed-out pages, append rows in the same shape to the STATEWISE / NATIONAL_MGMT arrays in this file's script, or replace them entirely once a richer extract is available — for example a state-wise management breakdown, a UDISE+ infrastructure module, ASER learning-outcome tables, or an NSS/MOSPI household-expenditure-on-education extract. The rendering functions read from these two arrays only, so a wider dataset with the same column names will flow straight through.
